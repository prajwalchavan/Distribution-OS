**Cut line if the schedule slips, in order:** retailer PWA → incentives v1 → WhatsApp draft orders → bargain flow → directory → live map (fall back to a trip list with "last seen"). **Never cut:** GRN-by-photo, brand-DMS ingestion, offline orders, billing/GST/print, receivables, Tally XML export, delivery + collections + GPS + settlement, owner dashboard, WhatsApp invoices, backups and the restore drill.

### 3.2 v1 (post-pilot months 1–3)

Claims aggregate with per-brand statements (data already stamped); Windows Tally Connector (Node SEA); payment-behaviour bands A/B/C; near-expiry ladder; WhatsApp voice and photo intake after the benchmark; Marathi strings (keys exist from day one); retailer native binary if PWA data justifies; second and third tenants; Multi-AZ RDS; DR copies to ap-south-2.

### 3.3 Later (month 6+)

E-way bill and outbound IRN via a GSP when a tenant needs it (₹5 crore B2B, R05 §4); EWB "expected deliveries" inbox and GST taxpayer API enrichment; Bluetooth ESC/POS slips (pilot van sales send the slip as a WhatsApp PDF and use the OS share-to-print sheet — RN thermal libraries are fragile and this is not on the cut line); rep voice ordering; ONDC NP-MSN at ~20 tenants; ClickHouse only if measured; PowerSync self-host only if residency forces it.

### 3.4 Must-not-build

Separate binaries per role or a Manager desktop app (release load, R07 §2.3); route optimisation/VRP (owner beats + Google Routes; VRP matters above ~5 vehicles, R03 §11); ONDC seller app in the pilot (vocabulary only; R04 §3.5); payments aggregator, wallet, lending, BNPL (founder; own-VPA UPI QR + UTR); own OTP/JWT stack, Firebase phone auth, Twilio Verify (30–60× the India price, R07 §8); Redis, Kafka, a second datastore, microservices (pg-boss + LISTEN/NOTIFY carry ~100 tenants, R08 §5); RDS Proxy at pilot and any WebSocket transport (§9, §11); OCR-then-LLM, specialist parsers, on-device models (R06 §1–4); Marg DBF/Busy XML readers (Excel/CSV profiles, R02 §5); shelf-photo/planogram analytics (R10 §2.15); live chat for bargaining, all-day GPS of reps, geo-fence billing gates (CONTEXT, R01 §5.2); no-code configurability; a cross-platform UI kit spanning RN and DOM (§8); per-device licensing and opaque pricing.
