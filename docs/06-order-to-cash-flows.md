# Order-to-cash flows per app

**Salesperson (offline).** Opens on "Aaj ka beat" with last-order and outstanding chips from `retailer_outstanding_summary`. Check-in stores the geo-tag as evidence with `distance_m`; outside the fence is amber, never a block. Order opens on "Reorder last order" or suggested v1 (median inter-purchase gap and quantity, scheme-inflated orders excluded); quick grid filtered by the rep's authorised list; case/pcs stepper ("2 case = 180 pcs"); pending-undelivered inline; ATP from `sellable_stock`. The pure engine prices each line at the effective version and stores `applied_rules` and `priced_at`; credit control runs locally (`indicate` annotates, `strict` opens an approval, `stop` blocks with the owner override path); MOV override logged; bargain request if outside the auto-approve bound. Submit → `submitted`; PowerSync uploads when connectivity exists; status dot only. Server recomputes (§7.3); the retailer's WhatsApp confirmation goes out; the rep sees `confirmed` or a "Needs attention" item. Performance tab: target, achievement, computed incentive.

**Manager / warehouse.** Inbound: capture → review → GRN (§5); stock visible to reps within one sync. Order queue grouped by beat/trip → trip + picklist consolidated by SKU with FEFO warn. Pick with actual lot; pack per order; short-packs are `pack_confirmations` rows, never edits to order lines. Billing desk (web): invoice from packed quantities — series number, GST split by place of supply, `applied_rules` copied to invoice lines, own-VPA UPI QR payload, FSSAI, ORIGINAL/DUPLICATE; PDF rendered by the API so mobile and web print identically; "dispatched" template with the PDF. Load sheet (last stop loaded first); check-out counts by the crew confirmed with the manager's PIN → `transfer_out` warehouse / `transfer_in` vehicle in one transaction. Day-end: Too Yumm DMS invoices photographed and committed so the ledger is whole.

**Delivery (offline, trip-scoped GPS).** "Start trip" → consent recorded once; foreground notification "Trip in progress — location shared with Tarsun Enterprises"; points buffered and batched to `/gps/points` (§7.5). Opens on the next stop; Google Maps hand-off; retailer phone visible until delivered. One tap `delivered`, or `partial` with reason and per-line qty, or `failed`; ePOD bundle (photo, optional OTP/signature, lat/lng, time) per tenant policy; shortfall → credit note; returns saleable/damaged → `sale_return_*` into the vehicle location. Collect cash / UPI with UTR / cheque as an append-only receipt with a client receipt number; allocation bill-to-bill oldest first unless tagged; cash counts toward expected cash. On-spot order: the rep order screen against the vehicle location; invoice at delivery; slip via WhatsApp PDF and the OS print sheet. Retailer receives invoice + POD + UPI QR, then the receipt template. Check-in: counted return of unsold stock; settlement cockpit shows expected vs declared cash, expenses, variance; outside tolerance → red; trip cannot close without owner approval.

**Owner.** Phone: `owner_summary` tiles (collected today, cash in transit, outstanding by age, orders/dispatched/delivered, at-risk stock), approvals (price variance, credit, MOV, bargain, red settlement, GRN exceptions), live map from `vehicle_positions`. Console: price lists and schemes with validity, overrides, credit modes; coverage vs universe; profit view (owner stream only); registers and exports; Tally mapping and export; imports wizard; settings (series, ePOD policy, settlement tolerance, DPDP notices); curation queue; incentives.

**Retailer (WhatsApp → PWA → native).** Every invoice, POD and receipt arrives on WhatsApp with a PWA deep link. Free text ("bhai 2 case campa 1L kal") → LLM parse against the retailer's own SKU history → draft order in the distributor's approvals → confirmation template. PWA: one card per linked distributor; reorder, running-low, deals, ATP-aware quantities; order status from the fulfilment machine; outstanding screen shaped like the pending-bills file with UPI QR; request discount; shop-detail self-edit (never credit/tier); directory opt-in with new links prepaid.
