# Frontend architecture

| Concern                  | Decision                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mobile                   | Expo SDK 57 (RN 0.86, New Architecture only, pinned), TypeScript, `expo-router`, EAS Build + Update with runtime-version gating, development builds from day one (Expo Go cannot run background location, op-sqlite or push)                                                                                                                                                       |
| Team app                 | `app/(auth)/ (owner)/ (sales)/ (warehouse)/ (delivery)/`; root layout mounts only permitted groups from membership roles; role switcher; routes declare `requires: ability(...)`; the sales module never bundles cost screens                                                                                                                                                      |
| Retailer app             | Separate Expo project, web output first (PWA on CloudFront), native later; online-first via oRPC + TanStack Query with persisted cache; CI bundle budget                                                                                                                                                                                                                           |
| Console                  | Vite + React 19, TanStack Router/Query/Table, oRPC client, Tailwind on shared tokens, PWA on S3 + CloudFront; MapLibre + Ola tiles for the map (Google dynamic maps cost on web); PDFs rendered by the API                                                                                                                                                                         |
| Local data               | PowerSync + op-sqlite (Team only); TanStack Query for online calls; Zustand for UI state only                                                                                                                                                                                                                                                                                      |
| Styling (resolved)       | `frontend/packages/ui/tokens.json` → generated RN `StyleSheet` theme and a Tailwind preset. RN primitives (NumberPad, QtyStepper with case/pcs, MoneyText, StatusPill, RowCrop, CandidateChips, SwipeActions, ListRow) shared **between the two Expo apps**, not with the DOM. No Tamagui, no NativeWind: a compiler toolchain on a New-Arch-only SDK is churn risk for one person |
| GPS                      | `expo-location` + `expo-task-manager`, trip-scoped, Android `foregroundServiceType="location"`, iOS background indicator, `Balanced`, 50 m / 30 s, `AutomotiveNavigation`; Play declaration, disclosure dialog and ≤ 30 s video in week 21; Transistorsoft ($399) as the OEM-battery-killer fallback (R07 §4)                                                                      |
| Maps / camera            | `react-native-maps` on Google's mobile SDK behind `MapProvider`; URL hand-off for navigation; `expo-camera` (ML Kit) for EAN/QR; document scanner at full quality                                                                                                                                                                                                                  |
| i18n                     | `i18next` + `expo-localization`; `hi`, `en` shipped, `mr` reserved; Noto Sans Devanagari; `Intl.NumberFormat('en-IN')` with a lakh/crore fallback in `shared/domain`; template bodies share keys with UI strings                                                                                                                                                                   |
| Push / testing / cadence | Expo Push for staff; Vitest for domain; Maestro flows (order-offline, GRN-review, deliver-stop, settle-trip); role-leak dump in CI; one native release per quarter, the rest via EAS Update                                                                                                                                                                                        |

**Zero-training UX rules (from C), enforced as design-system lint:** every screen opens on the most likely action ("Aaj ka beat", next stop, GRN queue, "Reorder last order"); numeric input is a keypad, never a text field, stepper defaults to the last quantity, case/pcs shows both; state is colour + icon + word; no modal blocks for sync, GPS or permissions; geo-fence outside is an amber flag; the retailer sees the same object the invoice prints from; owner numbers are rupee outcomes first; Hindi/English toggle in every header, brand names untouched; the session survives a phone call and a day without signal; no "sync now" button.
