# Five-apps verdict and surface map

**Verdict: keep five products; ship two store binaries plus one web console.** **[CHANGE]** to packaging, not scope; all three proposals and all judges agree. The Team app is the only artefact that needs background location, a location-typed foreground service and camera-for-documents — the permissions that trigger the Play Console declaration form, prominent-disclosure dialog and demo video (R07 §4.2). Five binaries would mean five EAS pipelines, five listings and five quarterly SDK upgrades for one person (R07 §2.3).

Vehicle is a stock location, Trip is an aggregate, on-spot orders are fulfilled and invoiced from the vehicle, no separate app (R09 §3, R03 §7; Tarsun already issues Campa slips, invoice G). The founder must confirm with Tarsun before week 1, because delivery crews then inherit stock-ledger responsibilities (R07 §13).

**Resolved here.**

- _Retailer codebases_ (A/B: separate Vite PWA + Expo app; C: one Expo project with web output). **Decision: C's packaging with A's data access.** One Expo Router project `frontend/apps/retailer` builds to web now and native later; it uses oRPC + TanStack Query with a persisted cache, never PowerSync. The order editor, product search and invoice viewer are React Native components shared with the Team app — the real reuse win. Judge 2's RN-web bundle concern is handled by a CI budget (≤ 600 KB gzipped initial route, per-route-group splitting) and by retailers arriving through a WhatsApp deep link to one screen.
- _Retailer on PowerSync_ (B `retailer_me`, C `retailer_scope`) vs online-first (A). **Decision: A.** PowerSync Pro bills $30 per 1,000 peak clients with a Free tier of 50 (R07 §3.1); Tarsun's ~150 retailers alone break Free during the pilot, 100 tenants would be ~15,000 clients, and lakhs would force self-hosting. Retailers order from a shop with 4G and do not need offline writes. PowerSync is reserved for the four staff roles; revisit only if self-placed orders exceed ~20% of volume and a measured offline need appears.
