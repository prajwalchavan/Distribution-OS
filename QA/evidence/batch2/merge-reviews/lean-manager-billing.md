   **Fix (load-out.tsx only, plus one string):** keep the ready URL in state (`challanUrl`). In the poll's `open` step, call `documents.open` only when `tries === 0`; otherwise set `challanUrl` and the note to a new `m7.challanReady` ("The challan is ready — press Print the challan"). Make the button's `onPress` open `challanUrl` synchronously when it is set (before any await), else start the poll. Reset `challanUrl` with the note on close. Extend `nextChallanPoll` or its test only if the step gains an `attempt === 0` flag; the current three tests stay green either way.
